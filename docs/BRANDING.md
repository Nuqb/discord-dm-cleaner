# Logo

`assets/logo.png` is the transparent, high-resolution project logo.
`assets/cleaner.ico` is its Windows icon, embedded into the executable.

To display the logo in your personal GitHub README:

```html
<a href="https://github.com/Nuqb/discord-dm-cleaner">
  <img src="https://raw.githubusercontent.com/Nuqb/discord-dm-cleaner/main/assets/logo.png" width="96" alt="Discord DM Cleaner" />
</a>
```

The artwork was generated for this project and incorporates the recognizable Discord Clyde symbol with a DM envelope. It is an unofficial project identity,
and does not imply endorsement by Discord. Discord branding belongs to Discord.
