# v1.0.0

First public release. Earlier local prototype numbers have been reset to 1.0.0.

- Portable Windows app with a dark interface and built-in setup guide.
- Scan a one-to-one DM and review your account, recipient, and eligible count.
- Confirmation phrase and per-message ownership checks before deletion.
- Cancellation, pagination, rate-limit handling, and simulated regression tests.

Download `Discord-DM-Cleaner-v1.0.0-Windows.zip`, extract it, and open
`DiscordDmCleaner.exe`. No installer or additional app files required.
`SHA256SUMS.txt` provides the ZIP's SHA-256 checksum.

Requires Windows with .NET Framework 4.x. The executable is unsigned.
Deletion is permanent. Account tokens are sensitive. Discord prohibits personal
account automation and may terminate accounts for it. This app is unofficial;
live Discord compatibility has not been verified. See START-HERE.txt before use.
