# v1.0.1

Replaces the generic speech-bubble-and-eraser artwork with a Discord-focused
Clyde and DM envelope icon. The README logo, Windows executable icon, and
in-app window icon use the same artwork. Cleanup behavior is unchanged.

Download `Discord-DM-Cleaner-v1.0.1-Windows.zip`, extract it, and open
`DiscordDmCleaner.exe`. `SHA256SUMS.txt` provides the ZIP checksum.

Requires Windows with .NET Framework 4.x. The executable is unsigned.
Deletion is permanent. Account tokens are sensitive. Discord prohibits personal
account automation and may terminate accounts for it. This app is unofficial;
live Discord compatibility has not been verified. See START-HERE.txt before use.
